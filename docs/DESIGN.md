# 설계 규칙

## 게임 방향

- **플레이어의 자유**: 정해진 직업·목표가 없다. 무엇이든 될 수 있고, 무엇을 해도 세계가 반응한다.
- **세계의 자율성**: 플레이어가 없어도 주민의 삶이 굴러간다. 매일 아침 신문에 주민들의 삶이 실린다.
- **이야기의 축적**: 일어난 일은 기억·소문·신문·연대기로 남고, 다음 사건의 원인이 된다.
- **확장성**: 나라·종족·직업·주민·아이템이 계속 늘어날 수 있어야 한다. 게임 안에서 주민이 새 나라를 세우거나,
  새 종족(예: 용족)이 섞여 들어오는 일도 일어난다.
- **비용 0**: 주민의 판단에 AI 호출을 쓰지 않는다. 성격·꿈·관계를 가중치로 쓰는 규칙 기반 판단.
- **새로 시작하면 새 세계**: 다시 태어나기는 새 세계에서 처음부터 시작한다.
- **알려 주지 않는 재미**: 도감은 내가 얻어 본 것만 쌓이고, 전체 개수를 보여 주지 않는다.
  모르는 지식이 필요한 만드는 법은 보이지 않는다.

## UI (jungrok5/ai-design 기준)

- 장식용 이모티콘 금지. 아이템은 게임 안 도트 아이콘으로 보여 준다.
- 그라데이션·글로우·장식 그림자 금지. 1px 선, 모서리 6/8/10.
- 강조색은 하나(`--accent`)만, 행동·상태에만 쓴다. 상태를 색으로만 구분하지 않는다.
- 문구는 짧게. 설명 문장을 화면에 늘어놓지 않는다. 얻는 법 같은 세부 정보는 도감으로.
- `word-break: keep-all`, 터치 대상 44px 이상. 375 / 768 / 1024 / 1440 폭에서 확인한다.
- 휴대폰: 창은 화면을 거의 채우고 안에서 스크롤, 대화 선택지는 아래에서 올라오는 시트.

## 그림 (16px)

- 타일 16px, 화면에서는 정수배(3~4배)로 키운다. 해상도를 올리지 말고 그리는 법으로 퀄리티를 낸다.
- 색: **B 톤** (`art/art.js`의 `RAMP`). 채도를 낮춘 따뜻한 톤.
  재질마다 실제로는 세 톤(그림자·기본·밝음) + 선·반짝임만 쓴다. 계단이 많은 그라데이션 금지.
- 빛은 왼쪽 위에서. 그림자는 오른쪽 아래.
- 굵고 어두운 외곽선(`INK` = `#2a2226`). 덩어리끼리 겹치는 경계에도 짙은 선.
- 질감은 점 잡음이 아니라 결(풀 포기, 널빤지, 기와 줄, 짚단)로.
- **조각 조합**: 인물은 몸 + 머리 모양 + 윗옷/덧옷/하의 + 모자 + 손에 든 것 + 종족 특징(귀·뿔·꼬리·수염)을
  색 램프와 함께 겹쳐 그린다. 직업은 그림이 아니라 '조합표'만 가진다. 새 모자·옷은 앞·옆·뒤 세 방향 틀만 더하면 모두에게 맞는다.
- 건물은 `building({ w, wall, roof, door, windows, chimney, sign, annex, porch, snow … })`로 조립한다.
- 특정 게임의 그림·건물·캐릭터를 베끼지 않는다. 장르의 느낌만 참고한다.

## 문체

- 시스템 문구는 평서문 ("나무 밑에서 마른 나뭇가지 3개를 주웠다."). 주민 대사는 해요체.
- 한국어 조사는 `jo(이름, "이/가")`로 붙인다.
